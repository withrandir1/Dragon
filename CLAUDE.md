# Memescan — контекст проекта

Сканер pump.fun-мемкоинов: вход по перевесу покупок, выход вместе с «информированными» (создатель, топ-3, кластеры).
**Только бумажная торговля.** Реальные ордера — только после доказанного преимущества и явного решения владельца.

## Запуск и проверка
- `python3 server.py` → http://localhost:8787 (stdlib, без зависимостей); `--demo` — синтетика без сети.
- `python3 -m unittest -v tests.test_strategy` — прогонять перед каждым коммитом.
- Данные: GeckoTerminal (пулы, сделки), Solana RPC (холдеры, цена и потоки из хранилищ PumpSwap каждую секунду), DexScreener (резервная цена).

## Устройство
- `memescan/strategy.py` — фильтры, вход/выход (чистая логика).
- `memescan/ticker.py` — посекундная цена, скорость 1с/15с/30с, on-chain поток покупок/продаж, балансы китов.
- `memescan/whales.py` — холдеры, создатель (из bonding curve), кластеры по общему фондированию.
- `memescan/economics.py` — издержки круга, размер позиции, проверка «ожидание ≥ 2× издержек».
- `memescan/research.py` — проверка гипотезы: доходность сигналов через 5/15/30 мин по силе перевеса.
- `memescan/engine.py` — скан, позиции, вход/выход в реальном времени. `web/index.html` — интерфейс.

## Решения владельца
- Перевес ×2 (покупки $ ≥ 2× продаж) — вход и удержание; выход, если продаёт создатель (≥10%), любой из топ-3 (≥20%) или кластер (≥20%); стоп −15%.
- Только мигрировавшие pump.fun-монеты с ликвидностью; защита от слива одной сделкой важнее иксов.
- Приоритет — сохранение капитала; любые заявления о доходности — только по данным research/журнала.

## Не проверено на живых данных (проверить первым делом)
- Раскладка аккаунта пула PumpSwap (адреса хранилищ со смещения 139/171, база сверяется по mint).
- Комиссия PumpSwap (в конфиге 1%/сторона), id пулов `pumpswap` в GeckoTerminal.
