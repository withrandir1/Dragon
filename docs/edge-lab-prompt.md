# Промпт для новой сессии Claude Code (папка ~/trading/edge-lab)

Ты мой исследователь торговых сигналов. Цель — найти ОДИН сигнал с реальным преимуществом после издержек и доказать это на истории. Только исследование и бэктест: никаких ключей, ордеров и реальных денег.

## Гипотезы (проверяй по порядку, каждую отдельно)
1. «Накатывающая волна»: агрессивные покупки ≥ 2× продаж (taker buy vs sell) за N минут И цена растёт → вход; дисбаланс ушёл → выход. Перебери N ∈ {1, 3, 5, 15} и порог ∈ {1.5, 2, 3}.
2. «Хаос толпы» — перегрев: экстремальный funding + рост open interest + резкое движение → вход против толпы; выход при нормализации funding.
3. «Каскад ликвидаций»: падение/рост ≥ X% за ≤ 5 минут на аномальном объёме → вход на откат; короткое удержание, жёсткий стоп.

## Данные (бесплатно, качай сам)
- Binance USDT-M фьючерсы, 1m klines за 12–24 мес. с https://data.binance.vision (в klines есть taker buy volume → продажи = volume − taker buy). Funding и metrics (OI) там же.
- Монеты: 30–50 ликвидных, обязательно мемы с перпами (PEPE, WIF, BONK, POPCAT, FLOKI, SHIB, DOGE, MEW, BRETT, NEIRO…) + BTC, ETH, SOL для сравнения.
- Hyperliquid (https://api.hyperliquid.xyz/info, candleSnapshot, fundingHistory) — для сверки и как площадка исполнения.

## Методика (строго)
- Без заглядывания в будущее: сигнал по закрытой свече, вход по open следующей.
- Издержки: Binance taker 0.05%/сторона, Hyperliquid taker 0.045%/сторона + проскальзывание 0.02–0.05%/сторона (больше для мелких мемов).
- Разделение: подбор параметров на первых 70% времени, вердикт только по последним 30% (out-of-sample). Отдельно по каждой монете и в сумме.
- Метрики: число сделок, средний результат на сделку после издержек, winrate, profit factor, макс. просадка, доля прибыли от топ-5 сделок (проверка на случайность).
- Сравнение с базой: случайные входы с тем же удержанием.

## Итог

Пиши кратко, по-русски, начинай с результата. Не утверждай доходность без цифр out-of-sample.
